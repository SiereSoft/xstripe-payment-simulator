# Support

## Where to go

| You want to… | Go here |
|---|---|
| Ask how to do something | [Discussions](https://github.com/SiereSoft/xstripe-payment-simulator/discussions) |
| Report incorrect behaviour | [Open a bug report](https://github.com/SiereSoft/xstripe-payment-simulator/issues/new?template=bug_report.yml) |
| Report a difference from real Stripe | [Open a fidelity gap](https://github.com/SiereSoft/xstripe-payment-simulator/issues/new?template=fidelity_gap.yml) |
| Report a vulnerability | [SECURITY.md](SECURITY.md) — privately, never a public issue |
| Propose a change | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Before you ask

Most questions are answered by the README: configuration, the endpoint list, the
test cards that drive each outcome, seeding and reset, the clock, and the
[honest limitations](README.md#honest-limitations-today) section — which is worth
reading first, because some "bugs" are documented scope decisions.

## What this project is not

It is a local simulator for development, testing, and agent evaluation. It is not a
payment processor, not a Stripe product, and not supported by Stripe. Please read
[DISCLAIMER.md](DISCLAIMER.md).

We cannot help with questions about **real** Stripe integrations — those belong with
[Stripe support](https://support.stripe.com).

## Response expectations

This is maintained by a small team alongside other work. Issues are read, but there
is no response-time guarantee and no commercial support attached to this repository.
Well-specified bug reports with a reproduction get handled fastest.

Commercial enquiries: **hello@sieresoft.com**.
